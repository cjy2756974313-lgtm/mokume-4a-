## 五、过程中发现并修复的问题

1. **【重大】cut1 切面朝向差 90°**：官方 cutA 坐标与照片木纹走向差约 90°
   （col_cube 同样错 → 与 4a 无关）。`4a_eval_cut.py` 对 cut1 补一次
   `cv2.ROTATE_90_CLOCKWISE`；修复后 11 样本走向偏差 ≤11°，
   cut1 三样本 SWD2 0.318/0.401/0.441 → 0.233/0.289/0.327。
   教训：warpAffine 旋转测方向被边界效应污染，必须用结构张量。
2. **可视化颜色还原失真**：原用外表面 2/3+1/3 混合近似切面色，偏差大
   （B08 偏红 +33、BW06 偏灰 −25）。2026-10-15 曾改为用 GT 切面自身通道均值定色——
   ⚠️ **该做法违反严格留出协议（评价图不得使用目标切面颜色统计），已于 2026-10-21 回退**：
   现取六面外表面 A-F_col.png 通道均值的平均作为展示定色（`4a_eval_cut.py:193-203`）。
   指标始终在白平衡域计算，对定色方式免疫。
3. **`proc_eval.json` 双格式陷阱**：`4a_proc.py` 内置 cut2 自检写扁平格式，
   导致 runner 误判评价已完成。修复：`eval_done()` 校验 `metrics` 键。
4. **sweep_beta 残留状态**：扫描循环把体数据与评价留在最后一个 β（0.0）。
   已打补丁收尾自动还原 β=1。
5. **summary.json 过期问题**：事后重评价（朝向修复 / β 调整）后
   summary 不再反映现状。新增 `refresh_summary.py` 统一口径。

## 六、规律性发现（详见 `tune_registry.md`）

1. **射线层几乎总被关掉**：11 样本 10 个射线尺寸落最小档，参数停在初值 → 射线判别力最弱。
2. **针叶材退化是解剖学正确**：桧木无导管，Stage C 自发选最小管孔档（H06/H11）
   或拟合极弱值（H01），与真实结构一致。
3. **环孔材（栗）是最大短板**：CN03 参数全停初值成退化样本（SWD2 0.5352 当前最差）；
   CN01 大管孔为真实结构，β 衰减反而单调变差。
4. **β 需求与暗度非单调**：BW02 管孔最暗只需轻微衰减，BW06/CH06 暗度中等却需 0.5。
5. **协议纪律（2026-10-21 修订）**：原记录称"全部主表数值保持 β=1 纯拟合、β 扫描仅作分析记录"，
   但复核发现：**B08/BW02/BW06/CH06 四块的正式体数据实际停留在 β<1（由目标切面 SWD2 选出）**，
   且 11 块恢复样本的评价报告早于体数据落盘（CN03 数值无法复现）。
   现协议纪律为：
   - 生成只能用六面外表面 `A-F_col.png` + 冻结的 `gf_params.pkl`；
   - 目标切面 **只** 在 `4a_eval_cut.py` 中读取一次，且只在 `proc_cube.npz` 落盘之后；
   - 禁止任何按切面指标选参（β 扫描 / 网格搜索 / 颜色提示提取）；
   - 评价图定色只能用外表面统计或中性定色；
   - `sweep_beta.py`/`tune_details.py` 保留在 `diagnostics/`，其产物（`proc_cube_beta1_backup.npz`、
     `proc_params_beta*.pkl`）已隔离在 `diagnostics/quarantine/<ID>/`，不得回流正式结果。
