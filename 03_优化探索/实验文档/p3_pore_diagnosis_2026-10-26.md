# P3 诊断：按环内相位分箱的管孔分布（2026-10-26）

> 承接 Gate 2A（`g2a_results_2026-10-26.md`）——c7 不冻结，按预登记分流进入 P3。
> 本文是 P3 的**第一步：先量化，再决定加什么损失**。不含任何训练改动。
> 工具：`p1/code/pore_profile.py`（新增，可复用）

---

## 0. 一句话

相位分箱的管孔分布诊断显示：程序的**相位位置**大体对（K04 corr 0.81），但**幅度与相位条件化**有系统性缺陷——
B08/NR04 的管孔几乎"不随相位变化"、K04 缺晚材管孔、KR07 在 u≈0.72 处画出一条**15 倍过强的假环孔带**。
c7 只把 KR07 的这条带从 20% 压到 4%（obs 1.1%），对 B08/K04 基本无改善，对 NR04 反而让管孔更少。

**结论：P3 要修的是"管孔幅度随相位的分布"，不是继续调颜色项。**

## 1. 方法（可复现）

| 项 | 做法 |
|---|---|
| 相位坐标 | 由冻结生长场重算 `u = alfas`（与训练同一口径，不含可训练量） |
| 有效像素 | 剔除 `u ≥ 0.999`（最后一个环界之外，clamp 到 1 的区域）与图像边界 3 px |
| 管孔代理 | 亮度低分位阈值（每面 8% 分位）→ 二值 → 2×2 开运算去噪；**同一检测器同时用于照片与渲染**，避免"程序掩码 vs 照片"的口径混用 |
| 分箱 | 16 箱，箱内统计暗像素占比 d(b)、暗斑数/千像素、平均暗斑面积 |
| 参数化 | 拟合 λ(u)=λ_bg+λ_E·exp(−½((u−0.15)/0.12)²)+λ_L·u（最小二乘，报告 R²） |

命令：
```bash
python pore_profile.py -root $EXP -ids B08,KR07,K04,NR04 \
  -tags g2a_base_s1001,g2a_c7_s1001 -faces_subdir faces_g2a \
  -out $EXP/logs/pore_profile_v2_s1001.json
```
（先试过不加有效掩码的版本，结果被外缘暗区污染——B08 的最后一箱 obs 13.9% / proc 12.7% 全是边界效应；已修正。）

## 3. 四条结论（P3 的设计依据）

1. **散孔材（B08）：管孔几乎不落在环内**。obs 在箱 4–10 有 2–4.4% 的连续暗区，proc 在这段≈0，只在 u→1 有一条 10% 的边带。相对质量误差 92%，c7 无改善（87%）。
   → 程序的 `pore_occurance_ratio` 对 B08 太小，且 `pore_occ_ring_correlation` 只做了线性倾斜，做不出"环内散布"。

2. **半环孔材（KR07）：画出了 15 倍过强的假环孔带**。base 在箱 11（u≈0.72）达 20%，obs 全剖面只有 0.5–2.1%；c7 压到 4%（仍 8 倍）。
   → 这正是 Gate 2A 里 KR07 detail 相位 +62~84% 的来源：一条不该存在的暗带被写进了环相位剖面。

3. **环孔材（K04）：早材对了，晚材管孔缺失**。obs 尾箱 8.5/12.3%，proc 2.3/6.4%；形状相关 0.81 说明"位置对"，缺的是**晚材那一段的幅度**。
   → `pore_latewood_occ` 在 K04 上几乎没起作用（Gate 2A 里 K04 该参数漂移也最小）。

4. **环孔材（NR04）：管孔分布几乎与相位无关**。base 在 2–3% 之间平铺（形状相关 0.26），obs 是"早材 5–6% → 中段 0.5% → 尾段 5%"的三段式；c7 把整体量降得更低（1.42%→0.90%），形状相关反而降到 0.14。
   → NR04 的问题不是"管孔太多伤外观"，而是**没有相位结构**；它在 F1 上的改善（+8%/+19%）来自颜色/过渡，不是管孔。

| KR07 | −0.45 / 122% | −0.12 / 130% | **假环孔带再现**：base 在箱 11 达 6.8%，c7 达 **13.4%**（obs 0.5%）；两 seed 都出现，只是幅度 6.8–20% |
| K04 | +0.58 / 63% | **+0.72 / 43%** | 本 seed 里 c7 **明显改善**：恢复早材峰 10.5%，误差 63%→43% |
| NR04 | +0.29 / 85% | +0.29 / 84% | 两 seed 都是相位无关的平铺，c7 只降总量不改形状 |

要点：
1. **KR07 的假带是可复现的结构缺陷**（两 seed 都有，u≈0.7、幅度 6.8–20% vs obs 0.5%），不是单次噪声 —— P3 的第一优先级。
2. **c7 对管孔的作用方向不稳定**：K04 一个 seed 变好（+0.58→+0.72）、一个变差（+0.81→+0.75）；B08 一个 seed 略好、一个明显变差（57%→80%）。这与 Gate 2A 里 c7 的 F1 表现（K04 稳定回退、B08 混合）一致。
3. NR04 的问题在两 seed 都**不是幅度而是形状**（相位无关），任何只调幅度的项都救不了它。

## 4. 对 P3 的具体设计（下一步，未执行）

### P3-1 Stage C 语义化重构（首选，非梯度）

现状：Stage C 把 10 个离散细节参数**绑成 3 个标量** `fv/pv/rv`（`phi.fiber_disc.fill_(fv)` 等），
`pore_disc` 的 5 个分量被同一个 `pv` 填满 → 发生率、环相关性、晚材率、尺寸**无法分别搜索**。
这正好解释了上面四条：搜索空间里没有"晚材多、早材少、环内散布"这种组合。

改法：
- 维度拆成 `(pore_occ_base, pore_occ_ring_corr, pore_latewood_occ)` × `(pore_rad)`，各 3 档 → 81 组，
  但用**共同随机特征样本**（固定噪声种子）评同一组 6 面，避免排名噪声；
- 评价函数 = 现有风格损失 + **管孔相位剖面对齐项**（obs vs proc 的 d(u) 相关/幅度差，本文工具直接可算，不可导也没关系——Stage C 本来就是无梯度搜索）；
- 射线/纤维仍走原 `rv/fv`（它们不是本轮矛盾）。

### P3-2 软暗像素剖面损失（可选，梯度）

若 P3-1 后 KR07 的假带仍在，再把 `s = sigmoid((τ−lum)/w)` 的箱内均值作为可导统计，
以**低权重**（≤0.1）加进 Stage D。注意：**不要**复用 c7 的中位数颜色项——它已经被证明会在 detail 条件下压平箱内颜色。

### 不做

- 不用颜色项继续压 KR07/K04（Gate 2A 已证伪）；
- 不动 `pore_cont` 的梯度路径（其梯度 ~1e-7，加损失也无效）；
- 不用斜切面选参数。

## 6. P3-1 v1 实测（2026-10-26 16:25，res128 默认预算，4 样本 × seed1001）

实现：`-stagec_semantic 1`，语义网格
`occ_base{0.2,0.5,0.8} × ring_corr{0,0.3,0.6} × latewood_occ{0,0.5,1.0} × pore_rad{0,0.577,1.0} × ray{0.5,1}` = 162 组，
评分 = 风格损失 + 0.5 × 管孔相位剖面误差（**只用暗像素占比 d(u)**）。

| 样本 | 选中语义参数 | 管孔剖面 L1(obs) base→v1 | 外表面 F1 base→v1 |
|---|---|---|---|
| B08 | occ0.2 / ring0.0 / lw0.5 / rad**0** | 2.05 → **1.40 pp（−32%）** | 0.0276 → 0.0123（**−55%**） |
| KR07 | occ0.8 / ring0.0 / lw1.0 / rad**0** | 1.75 → **0.49 pp（−72%）** | 0.0224 → 0.0218（−3%） |
| K04 | occ0.8 / ring0.0 / lw1.0 / rad**0** | 1.81 → 2.06 pp（+14%） | 0.0650 → 0.0581（−11%） |
| NR04 | occ0.8 / ring0.3 / lw0.5 / rad**0** | 1.74 → 1.44 pp（−17%） | 0.1360 → 0.1006（**−26%**） |

**结论：v1 不成立。** 管孔剖面误差 3/4 改善，但环结构 F1 全面下降（均值 0.0628 → 0.0482，−23%）。

**失败机制（可诊断、可修）**：评分只用"暗像素占比"，对**暗斑大小不敏感**。
四块全部选了 `rad=0`（最小管孔口径 cell=0.01），于是优化器用"大量细小暗点"去凑相位剖面，
既满足了 d(u)，又不产生早材大孔那种能撑起环对比的暗区 —— F1 因此掉。
这正是框架 §5 P3 里点名要统计"管孔半径分位数 / 早材大孔与晚材小孔比例"的原因。

对应修法（已实现，待验证）：在评分里加**暗斑面积项**
`area_err = mean |log((area_proc+1)/(area_obs+1))|`，与占比项等权相加。

## 7. P3-1 v2（加暗斑面积项）与合并判定

v2 = 在 v1 评分里加面积项 `mean|log((area_proc+1)/(area_obs+1))|`，与占比项等权。同样 4 样本 × seed1001、res128 默认预算。

| 样本 | 管孔剖面 L1 base / v1 / v2（pp） | 外表面 F1 base / v1 / v2 |
|---|---|---|
| B08 | 2.05 / **1.40** / 1.46 | 0.0276 / 0.0123 / 0.0113 |
| KR07 | 1.75 / **0.49** / 1.41 | 0.0224 / 0.0218 / 0.0223 |
| K04 | 1.81 / 2.06 / 1.91 | 0.0650 / 0.0581 / 0.0485 |
| NR04 | 1.74 / 1.44 / **1.38** | 0.1360 / 0.1006 / 0.0936 |
| **均值** | 1.84 / 1.35 / 1.54 | **0.0628 / 0.0482 / 0.0439** |

v2 的选中参数：仍有三块选 `rad=0`（只有 K04 选 0.577），说明**面积项没能把优化器推向大管孔**；
F1 反而从 0.0482 掉到 0.0439。

**合并判定：P3-1（v1/v2）不成立，且方向错误。**
- 管孔相位剖面确实更容易被满足（v1 三块改善），但**环结构 F1 全面下降 23–30%**；
- 加面积项没有翻转这个趋势，说明不是"尺寸没约束"这么简单；
- 同时颜色相位剖面与 L1 也小幅变差（nodetail +0.0054~0.0059，L1 +0.0016~0.0019）。

**机制解释（本轮最重要的新信息）**：外表面 U-Net 判环主要依赖**明暗带（颜色）对比**，不是管孔斑点。
把暗像素按相位重新分布（更多、更匀的细小暗点）会抬高局部纹理噪声，反而稀释带对比 → F1 掉。
也就是说：**"管孔真实性"与"环可检出性"在这个检测器下是相互竞争的**，不能拿管孔统计当 F1 的代理去优化。

### 对后续的含义

1. **不要再用管孔统计去追 RingF1**（无论占比还是面积）。P3 若继续，只能作为"解剖真实性"的独立目标，并且必须加"带内亮度剖面不变"的硬约束，否则一定伤 F1。
2. **c7 的失败也不是"相位项不对"，而是"detail 条件下颜色分布被中位数项压平"**——两条负结果指向同一个瓶颈：**环对比主要靠颜色带，任何会改变带内亮度分布的目标都会反噬 F1**。
3. 计时：语义网格 162 组使单块成本增加约 3 min（v2 实测 2 并行 764–1089 s；base 同条件 537–620 s），单 job 估计 ~7 min，**已超表 3 的 6.4 min 承诺**。即使方向对，也要先把网格压到 ≤54 组。
