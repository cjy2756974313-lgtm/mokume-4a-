## 2. 怎么用

**只想看结果** → 读 `02_结果/RESULTS_38.md`（含 38 块五个指标的逐样本表与结论），口径细节见 `02_结果/eval_geometry.md`。

**想复现** → 用 `01_程序/`，典型链路：

```bash
# ① 生长场反演（每块一次）
python 3_infer_gf.py -id <ID>
# ② 程序纹理适配（约 4–6 min/块，单 job 独占）
python 4a_proc.py -id <ID>
# ③ 斜切面评价（只在适配完成后跑，绝不参与损失）
python 4a_eval_cut.py -id <ID>
python 4c_eval_dists_f1.py -id <ID>
# ④ 38 块统一重评（只读体，不重新生成）
python reeval_orient.py
```

> 依赖：Python 3.11/3.13、PyTorch（本地 cu128）、OpenCV、scikit-image；VGG16/19 与 U-Net 权重需按 `README_4A.md` 放置。**本目录不含权重与样本数据**（见 §3）。

**想知道"为什么不继续优化"** → 先读 `03_优化探索/审核包/00_FINAL_AUDIT_SUMMARY.md`（一页结论），再按需读 `04_METRIC_EVIDENCE_LEDGER.md`（每个数字的证据等级）。
